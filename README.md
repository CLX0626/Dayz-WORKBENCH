# DayZ 工作台（Dayz-WORKBENCH）

一个给 DayZ 服主和玩家用的配置编辑工作台。目前支持 Expansion 全套模组的配置编辑，用可视化界面代替手工改 JSON，改完保存自动备份，不用再怕手滑改坏配置文件。

## 能做什么

- **任务系统**：任务编辑器、10 类任务目标、任务依赖图（可视化连线）、思维导图
- **NPC / 交易商**：NPC 编辑器、交易商管理（.map 文件、交易区、Market、Hardline）
- **空投**：空投编辑器、战利品树
- **AI**：AI 编辑器、全局设置、分析仪表盘
- **装备**：装备管理 + 3D 纸娃娃预览
- **地图**：地图可视化查看与编辑、AI 位置/巡逻点标注
- **其他**：ATM、个人存储、污染区、玩法设置（25 个设置编辑器）、数据统计面板

## 数据安全

- 每次保存自动备份（.bak + 版本化备份目录，最多保留 10 份，可指定统一备份目录）
- 外部文件变更自动检测，未保存的修改会弹窗提醒，不会静默覆盖
- 撤销 / 重做全程可用

## 下载安装

1. 打开 [Releases 页面](https://github.com/CLX0626/Dayz-WORKBENCH/releases)
2. 下载最新版本的安装包（`-setup.exe` 结尾）
3. 双击安装，按提示操作即可

系统要求：Windows 10 / 11（首次运行如提示安装 WebView2 组件，按提示装一下就行）。

软件内置"检查更新"，有新版本会自动提醒，也可以随时在"关于"页面手动检查。
